# Security Policy

This repository is a fork of [mateuszsokola/2048-in-react](https://github.com/mateuszsokola/2048-in-react).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/mateuszsokola/2048-in-react/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
